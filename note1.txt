### Step 4 — Country Data Model ဖန်တီးခြင်း

#### ဘာလုပ်မလဲ (What)
`Country` model ကို ဖန်တီးပါမယ်။

#### ဘာကြောင့်လဲ (Why)
Country ကို data model အနေနဲ့ represent လုပ်ရင် — hard-coded boolean variables (isJapanSelected, isMyanmarSelected) မသုံးဘဲ — နောက်ပိုင်း China, Singapore, Vietnam စတဲ့ နိုင်ငံအသစ်တွေ ထပ်ထည့်ရတာ Calendar code ကို ပြန်မရေးရဘဲ ရပါတယ်။

#### ဘယ်လိုလုပ်မလဲ (How)

#### [NEW] [Country.swift](file:///Users/kyawwaiyan/Desktop/todo-calendar-app/HolidayCalendar/HolidayCalendar/Models/Country.swift)

```swift
import Foundation

struct Country: Identifiable, Codable, Hashable {
    let id: String          // UUID or country code
    let code: String        // ISO 3166-1 alpha-2 (JP, MM, AU, KR, TH)
    let name: String        // English name
    let localName: String   // Local language name
    let flag: String        // Emoji flag (🇯🇵, 🇲🇲, etc.)
    var isSelected: Bool    // User's selection state
    let timezone: String    // Primary timezone
}
```

> [!IMPORTANT]
> **Design Decision**: `Country` ကို `struct` (value type) အနေနဲ့ သုံးပါမယ်။ SwiftData `@Model` class မသုံးဘဲ `struct + AppStorage` approach ကို ရွေးပါတယ်။ အကြောင်းမှာ -
> 1. Country list က static data (server ကမလာဘူး၊ app ထဲမှာ define ထားတာ)
> 2. User ပြောင်းတာ `isSelected` property တစ်ခုထဲ
> 3. SwiftData ကို Todo, Memo, Holiday data အတွက် သုံးပါမယ်
> 4. Country selection state ကို `AppStorage` (UserDefaults) နဲ့ persist လုပ်တာ ပိုရိုးရှင်းပြီး သင့်တော်ပါတယ်

**Data Flow**:
```
Country struct (static data)
    +
Selected country codes (Set<String>) ← AppStorage (persisted)
    =
Runtime Country list with isSelected computed
```

### Step 5 — CountryViewModel ဖန်တီးခြင်း

#### ဘာလုပ်မလဲ (What)
Country selection logic ကို manage လုပ်မယ့် ViewModel ဖန်တီးပါမယ်။

#### ဘာကြောင့်လဲ (Why)
UI logic ကို data/business logic ကနေ ခွဲခြားထားရပါမယ် (MVVM pattern)။ ViewModel က single source of truth ဖြစ်ပြီး CountrySelectionView ရော Calendar ရော ဒီ ViewModel ကိုပဲ reference လုပ်ပါမယ်။

#### ဘယ်လိုလုပ်မလဲ (How)

#### [NEW] [CountryViewModel.swift](file:///Users/kyawwaiyan/Desktop/todo-calendar-app/HolidayCalendar/HolidayCalendar/ViewModels/CountryViewModel.swift)

```swift
@Observable
class CountryViewModel {
    // All available countries (static list)
    private(set) var countries: [Country]
    
    // Persisted selected country codes
    private var selectedCodesStorage: Set<String> {
        didSet { saveSelectedCodes() }
    }
    
    // Computed: countries with isSelected reflecting user's choices
    var countriesWithSelection: [Country] { ... }
    
    // Computed: only selected countries (for calendar filtering)
    var selectedCountries: [Country] { ... }
    
    // Computed: selected country codes (for filtering holidays)
    var selectedCountryCodes: Set<String> { ... }
    
    func toggleCountry(_ country: Country) { ... }
    func selectAll() { ... }
    func clearAll() { ... }
    
    // Persistence
    private func loadSelectedCodes() -> Set<String> { ... }
    private func saveSelectedCodes() { ... }
}
```

**State Management Flow (အသေးစိတ်)**:

```
User taps toggle
    ↓
CountryViewModel.toggleCountry(country)
    ↓
selectedCodesStorage (Set<String>) updated
    ↓
@Observable triggers UI update
    ↓
CountrySelectionView re-renders (toggle reflects new state)
    ↓
CalendarView re-renders (shows/hides holidays for that country)
    ↓
saveSelectedCodes() → UserDefaults persists the change
```

> [!IMPORTANT]
> **Single Source of Truth**: `CountryViewModel` ကို `@Observable` (iOS 17+ Observation framework) နဲ့ သုံးပါမယ်။ ViewModel တစ်ခုတည်းကို app-wide shared instance အနေနဲ့ Environment ကနေ inject လုပ်ပါမယ်။ ဒါမှ CountrySelectionView မှာ toggle ပြောင်းရင် Calendar မှာ ချက်ချင်း reflect ဖြစ်ပါမယ်။

### Step 7 — Country Selection Persistence ထည့်ခြင်း

#### ဘာလုပ်မလဲ (What)
Country selection state ကို app ပိတ်ပြီး ပြန်ဖွင့်ရင် ပြန်ရအောင် persist လုပ်ပါမယ်။

#### ဘာကြောင့်လဲ (Why)
User က Myanmar ကို OFF လုပ်ပြီး Australia ကို ON လုပ်ထားရင် — app ပိတ်ပြီး ပြန်ဖွင့်ရင် ဒီ state ပြန်ရရမယ်။ မဟုတ်ရင် user experience ညံ့ပါတယ်။

#### ဘယ်လိုလုပ်မလဲ (How)

**Persistence Strategy**:

```
UserDefaults (via AppStorage-compatible approach)
    ↓
Key: "selectedCountryCodes"
Value: JSON encoded Set<String> — e.g. ["JP", "MM", "TH"]
```

CountryViewModel ထဲမှာ:

```swift
private let selectedCodesKey = "selectedCountryCodes"

private func loadSelectedCodes() -> Set<String> {
    guard let data = UserDefaults.standard.data(forKey: selectedCodesKey),
          let codes = try? JSONDecoder().decode(Set<String>.self, from: data) else {
        // First launch: return default selections
        return ["JP", "MM", "TH"]
    }
    return codes
}

private func saveSelectedCodes() {
    if let data = try? JSONEncoder().encode(selectedCodesStorage) {
        UserDefaults.standard.set(data, forKey: selectedCodesKey)
    }
}
```

**Persistence Flow**:

```
App Launch
    ↓
CountryViewModel.init()
    ↓
loadSelectedCodes() from UserDefaults
    ↓
If first launch → return defaults: ["JP", "MM", "TH"]
If returning user → return saved codes: e.g. ["JP", "AU", "KR"]
    ↓
countries list populated with correct isSelected values
    ↓
UI renders correctly

User changes toggle
    ↓
selectedCodesStorage updated
    ↓
saveSelectedCodes() → UserDefaults
    ↓
Data persisted ✅
```

> [!TIP]
> **ဘာကြောင့် UserDefaults သုံးတာလဲ**: Country selection က ရိုးရှင်းတဲ့ user preference ဖြစ်ပါတယ် (country code ၅-၁၀ ခုလောက်ပဲ save ရတာ)။ SwiftData သုံးဖို့ ရှုပ်ထွေးလွန်ပါတယ်။ SwiftData ကို Todo, Memo, Holiday data တွေအတွက် သုံးပါမယ်။

## Architecture Overview (ဗိသုကာ အကျဉ်းချုပ်)

### MVVM Pattern

```
┌─────────────────────────────────────────────────────┐
│                       VIEW                          │
│  CountrySelectionView  │  CalendarView  │  Settings │
│         ↕                     ↕              ↕      │
├─────────────────────────────────────────────────────┤
│                    VIEW MODEL                       │
│              CountryViewModel (@Observable)         │
│  - countries: [Country]                             │
│  - selectedCountryCodes: Set<String>                │
│  - toggleCountry(), selectAll(), clearAll()         │
│         ↕                                           │
├─────────────────────────────────────────────────────┤
│                      MODEL                          │
│              Country (struct, Codable)               │
│         ↕                                           │
├─────────────────────────────────────────────────────┤
│                   PERSISTENCE                       │
│              UserDefaults (selected codes)           │
│              SwiftData (Todo, Memo, Holiday)         │
└─────────────────────────────────────────────────────┘
```

### Country Selection → Calendar Filtering (နောက် Phase အတွက်)

```
CountryViewModel.selectedCountryCodes
    ↓
CalendarViewModel uses selectedCountryCodes
    ↓
Filter holidays: holiday.countryCode IN selectedCountryCodes
    ↓
Display filtered holidays on calendar
```

ဒီ architecture ကြောင့် နိုင်ငံအသစ် ထပ်ထည့်ရင် Calendar code ကို ပြန်မရေးရပါဘူး။ Country list ထဲ ထပ်ထည့်လိုက်ယုံပါပဲ။
